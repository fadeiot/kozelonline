# Боярський козел — онлайн-сервер

Сервер роздає сторінку гри і тримає столи для гри з друзями.

- `server.js` — сервер (столи, запрошення, хід гри, боти на вільних місцях)
- `engine.js` — правила гри
- `ai.js` — боти
- `public/index.html` — сама гра (Telegram Mini App)

## Змінні середовища

| Назва | Що це |
|---|---|
| `BOT_TOKEN` | токен бота від @BotFather |
| `BOT_USERNAME` | логін бота без @, напр. `boyarskyi_kozel_bot` |
| `APP_NAME` | коротка назва Mini App з `/newapp`, напр. `play` |
| `ALLOW_GUESTS` | `1` — дозволити гру з браузера без Telegram (для перевірки) |

Без `BOT_TOKEN` сервер пускає будь-кого як гостя.

## Локальний запуск

```
npm install
node server.js
```
Гра відкриється на http://localhost:3000
