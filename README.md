# Боярський козел — онлайн-сервер і Telegram Mini App

Сервер роздає сторінку гри, тримає столи для гри з друзями, рахує статистику й надсилає нагадування через бота.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | сама гра (Telegram Mini App) |
| `engine.js` | правила гри — **одне джерело** і для сервера, і для сторінки |
| `ai.js` | боти (Новачок, Середній, Сильний, Дядя Слава) |
| `stats.js` | статистика і нагороди |
| `server.js` | сервер: столи, запрошення, пауза й автопілот, бот у Telegram |
| `botpool.js` | боти думають у фоновому потоці, щоб не гальмувати інші столи |
| `store.js` | збереження столів і статистики (Upstash Redis або файл) |
| `music.m4a` | фонова музика |
| `test/` | перевірки правил (`npm test`) і сервера (`npm run test:server`) |
| `sim.js` | турнір ботів: `node sim.js medium hard 60` |
| `build-standalone.js` | збирає гру одним файлом без сервера: `npm run build` → `dist/kozel-standalone.html` |

Файли можна класти в корінь репозиторію (як зараз) або в папку `public/` — сервер знайде їх в обох місцях.

## Змінні середовища (Render → Environment)

| Назва | Обов'язково | Що це |
|---|---|---|
| `BOT_TOKEN` | так | токен бота від @BotFather |
| `APP_NAME` | так | коротка назва Mini App з `/newapp`, напр. `play` |
| `BOT_USERNAME` | ні | логін бота; якщо не задано, сервер сам візьме його в Telegram |
| `UPSTASH_REDIS_REST_URL` | бажано | адреса бази Upstash Redis (REST URL) |
| `UPSTASH_REDIS_REST_TOKEN` | бажано | токен бази Upstash Redis (REST Token) |
| `ALLOW_GUESTS` | ні | `1` — дозволити гру з браузера без Telegram (для перевірки) |
| `KEEP_AWAKE` | ні | `0` — вимкнути самопінг (за замовчуванням на Render увімкнено) |
| `WEBHOOK` | ні | `0` — не ставити вебхук бота (якщо бот уже обслуговує інша програма) |
| `NOTIFY` | ні | `1` — увімкнути нагадування від бота «вас чекають за столом» (за замовчуванням вимкнено) |

`PUBLIC_URL` на Render задавати не треба: сервер бере адресу з `RENDER_EXTERNAL_URL`.

### Навіщо Upstash Redis
Без нього столи й статистика живуть у пам'яті та у файлі, який на безкоштовному Render стирається при кожному
перезапуску. З Redis партія, що йде, переживає оновлення гри, а статистика й рейтинг друзів не губляться.

1. Зареєструйтеся на upstash.com (безкоштовно), створіть базу **Redis** (регіон — Frankfurt).
2. На сторінці бази, розділ **REST API**, скопіюйте `UPSTASH_REDIS_REST_URL` і `UPSTASH_REDIS_REST_TOKEN`.
3. Додайте обидві змінні в Render → Environment і збережіть (сервис перезапуститься).

У журналі Render має з'явитися рядок `сховище: redis`.

## Як поводиться гра, коли хтось зник

* до 45 с — нічого не зупиняється (екран заблокували, перейшли в інший чат);
* з 45 с до 3 хв — пауза, всі бачать, хто вийшов і через скільки за нього гратиме бот;
* після 3 хв — за гравця ходить бот, гра йде далі; щойно гравець повернеться, він знову грає сам;
* господар столу може й раніше назавжди посадити бота на місце гравця.

## Бот у Telegram

Після запуску сервер сам ставить вебхук і команди бота: `/start` (кнопка «Грати»), `/stats` (статистика), `/help`.
Нагадування в особисті вимкнено (увімкнути: `NOTIFY=1`).

«Поділитися результатом» надсилає картинку в чат через `shareMessage` (Telegram 8.0+) або публікує її в історії.

## Локальний запуск

```
npm install
npm test
node server.js
```
Гра відкриється на http://localhost:3000 (без `BOT_TOKEN` — у гостьовому режимі).

## Швидкість онлайн-гри

* Сторінка перевіряє зв'язок кожні 3 с і показує затримку біля годинника (🟢 до 150 мс, 🟡 до 400, 🔴 більше).
  Якщо сервер мовчить 7 с, гра сама перепідключається і надсилає неперевірений хід ще раз (сервер відкидає дублікати).
* Безкоштовний Render має дуже слабкий процесор (0,1 ядра) і за замовчуванням сервер у США (Oregon).
  Для гравців з України й Канади найкраще — регіон **Frankfurt**. Регіон не можна змінити в наявного сервісу:
  потрібно створити новий Web Service з регіоном Frankfurt (у `render.yaml` вже вказано) і перенести змінні середовища.
* Найнадійніше — план Starter ($7/міс): без засинання й з повноцінним процесором.

## Як грати онлайн (просто)

* **Грати з друзями** — відкриває ваш стіл. Там список гравців, яких можна покликати, і кнопка «+ Посадити Дядю Славу».
* Формат визначається кількістю гравців за столом: 2 — на двох, 3 — на трьох, 4 — пара на пару.
* Почати гру, змінити довжину, посадити бота або завершити гру для всіх може будь-хто за столом.
* Вийти в меню — гра не зупиняється; повернутися — картка «Ваша онлайн-гра» в меню або просто відкрити гру знову.
* Після партії: «Ще партію» або «Вийти з гри» (місце звільняється, решта лишається за столом).

### Спільна зала (замість окремих столів)
Усі, хто натиснув «Грати з друзями», потрапляють в одну залу й бачать одне й те саме:
відкриті ігри з вільними місцями, хто зараз у грі й хто вже грає. Будь-хто відкриває гру потрібного формату
(на двох / на трьох / пара на пару), інші натискають «Сісти». Коли всі місця зайняті, партія починається сама.
«Решта — Дядя Слава» заповнює вільні місця ботами й запускає гру одразу.
